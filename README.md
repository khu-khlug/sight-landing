# sight-landing

쿠러그 메인 랜딩 페이지 개편을 위한 정적 웹사이트 프로젝트.

## Docs

- [콘텐츠 전략](./docs/landing-content-strategy.md): 랜딩의 핵심 메시지, 섹션 순서, 포함/제외 범위.
- [인터랙션 및 시각 디자인](./docs/landing-interaction-design.md): 반응형 구조, UI 구성, 애니메이션, CI 기반 시각 방향.
- [기술 아키텍처](./docs/landing-technical-architecture.md): Astro, React 컴포넌트, 데이터 수정, SEO, Cloudflare Pages 배포 기준.
- [문서 인덱스](./docs/landing-content-index.md): 랜딩 기획 문서 모음.

## Commands

- `nvm use`: Node.js `v24.18.0` 사용.
- `pnpm install`: 의존성 설치.
- `pnpm dev`: 로컬 개발 서버 실행.
- `pnpm check`: Astro 타입 검사.
- `pnpm build`: 정적 사이트 빌드.
- `pnpm preview`: 빌드 결과 미리보기.

## Stack

- Astro SSG
- React components
- TypeScript
- Vanilla TypeScript interactions
- CSS
- pnpm
- Cloudflare Pages
