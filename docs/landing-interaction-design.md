# 쿠러그 랜딩 인터랙션 및 시각 디자인

## 반응형 설계 원칙

랜딩 페이지는 데스크톱과 모바일을 모두 자연스럽게 커버해야 한다.

데스크톱에서는 넓은 화면을 활용해 2열 구성, 카드 그리드, hover/focus 인터랙션을 적극적으로 사용할 수 있다. 모바일에서는 모든 섹션을 1열 흐름으로 정리하고, 터치 가능한 영역을 충분히 크게 잡는다.

권장 방향:

- 데스크톱: 넓은 여백, 명확한 섹션 구분, 2열 또는 3열 카드 배치
- 태블릿: 2열 카드와 1열 본문을 혼합
- 모바일: 1열 구성, 가로 스크롤이 필요한 경우 칩/탭 정도로 제한
- 버튼과 칩은 터치하기 쉬운 높이와 간격 유지
- 핵심 CTA는 모바일에서도 첫 화면과 마지막 화면에 모두 노출

모바일에서는 hover가 없으므로, hover에만 의존하는 정보는 만들지 않는다. hover에서 보이는 정보는 tap/focus 상태에서도 접근 가능해야 한다.

## CI 기반 시각 방향

현재 랜딩은 흐릿한 사진 배경 위에 파란 그라데이션을 얹고, 최신 글 목록을 큰 영역에 배치하는 구조다. 새 랜딩에서는 이 방향을 유지하기보다 쿠러그 CI의 선명한 블록형 아이덴티티를 전면에 세운다.

핵심 컨셉:

> 파란 블록들이 모여 쿠러그를 만든다.

쿠러그 CI에서 확인되는 주요 인상은 다음과 같다.

- 선명한 파랑
- 두꺼운 직선형 한글 로고
- 정육면체와 블록 단위의 조합
- 각진 형태
- 그리드 기반의 질서
- 밝고 명확한 대비

따라서 홈페이지 전체는 부드러운 곡선, 흐릿한 사진, 과한 그라데이션보다 사각형, 큐브, 그리드, 블록을 중심으로 구성한다.

## 컬러

사용 컬러는 CI에 정의된 팔레트 안에서 제한한다.

```css
--color-primary: #00A0E9;
--color-sky: #79C7EA;
--color-blue: #0073B9;
--color-navy: #013E8D;
--color-white: #FFFFFF;
--color-gray: #EEEEEE;
--color-text: #222222;
--color-black: #000000;
```

역할:

- `#00A0E9`: 메인 브랜드 컬러, CTA, active 상태, 핵심 블록
- `#79C7EA`: 보조 블록, hover 배경, 옅은 강조
- `#0073B9`: 깊이감 있는 블록 면, 보조 강조
- `#013E8D`: 강한 대비, Hero 블록의 깊은 면, footer 또는 강조 배경
- `#FFF`: 기본 배경
- `#EEE`: 구분선, inactive 배경, 얕은 카드 배경
- `#222`: 본문 텍스트
- `#000`: 로고, 강한 텍스트, 고대비 장식

한 화면이 파란색 하나로만 보이지 않도록 흰 배경과 `#222` 텍스트를 충분히 사용한다. 파란색은 브랜드 인상을 만드는 포인트와 블록 그래픽에 집중한다.

## 타이포그래피

기본 폰트는 Pretendard를 사용한다.

CI 가이드라인에서는 Noto Sans CJK를 사용하고 있으나, 새 랜딩에서는 웹 환경의 가독성, 배포 편의성, 현대적인 화면 인상을 고려해 Pretendard로 변경한다. 이는 의도된 변경 사항이다.

권장 방향:

- 제목은 굵고 짧게
- 본문은 충분한 행간을 두고 읽기 쉽게
- 영문 라벨은 보조적으로만 사용
- 로고와 주요 문구는 한글 우선

CI 가이드라인에서도 한글 표기를 우선 사용하도록 안내하고 있으므로, Hero와 주요 내비게이션은 한글 중심으로 구성한다.

## 형태 언어

쿠러그의 핵심 identity 중 하나인 정육면체 형태의 상자를 UI 전반의 그래픽 언어로 사용한다.

적용 방식:

- Hero의 메인 비주얼
- 섹션 제목 옆 작은 아이콘
- 카드 좌상단의 블록 마커
- 관심 분야 칩의 선택 상태
- 가입 절차 stepper
- 이미지가 없는 최근 활동 카드의 placeholder

주의할 점:

- 모든 요소를 큐브로 만들 필요는 없음
- 본문 가독성을 해치지 않는 보조 그래픽으로 사용
- 둥근 카드나 pill 형태는 최소화
- border radius는 0~4px 정도로 제한

## 애니메이션 원칙

애니메이션은 한 구간에 강하게 집중하고, 나머지 구간에서는 정보 탐색을 방해하지 않는 수준으로 제한한다.

권장 방향:

- Hero 구간에 가장 강한 애니메이션을 배치
- 본문 섹션은 짧은 transition, hover, focus 효과 중심
- 스크롤할 때 모든 요소가 순차적으로 등장하는 방식은 피함
- 반복 애니메이션은 낮은 대비와 느린 속도로 유지
- `prefers-reduced-motion` 환경에서는 주요 애니메이션을 비활성화하거나 단순 fade로 대체

애니메이션의 목적은 페이지를 화려하게 만드는 것이 아니라, 쿠러그가 기술과 창작을 다루는 동아리라는 인상을 첫 화면에서 강하게 전달하는 것이다.

## 섹션별 UI, 인터랙션, 애니메이션

### Header

구성:

- 좌측: 심볼 + `쿠러그`
- 우측: `소개`, `활동`, `Hello`, `가입 신청`
- `가입 신청`은 가장 강한 CTA로 표시
- `로그인`은 메인 내비게이션에서 제외하거나 시각적 우선순위를 낮춘 보조 링크로 처리

스타일:

- 흰 배경
- 얇은 `#EEE` 하단 구분선
- 텍스트는 `#222`
- CTA는 `#00A0E9` 배경과 흰 글자
- 모바일에서는 심볼/로고와 메뉴 버튼만 노출

Header는 브랜드를 명확히 보여주되, Hero보다 시각적으로 강하지 않게 유지한다.

### Hero

Hero는 랜딩에서 가장 화려한 구간이며, CI의 정육면체 아이덴티티를 가장 강하게 보여준다.

구성:

- 제목: `경희대학교 중앙 IT 동아리, 쿠러그`
- 보조 문장: `처음이어도, 전공이 달라도, 함께 배우고 만드는 IT 동아리`
- 주요 CTA: `가입 신청하기`
- 보조 CTA: `활동 알아보기`
- 우측 또는 배경: 정육면체 블록 조립 그래픽

비주얼:

- `#00A0E9`, `#79C7EA`, `#0073B9`, `#013E8D`로 구성된 큐브
- 일부 큐브에는 `WEB`, `AI`, `SECURITY`, `APP`, `UX` 같은 짧은 라벨
- 큐브들은 단순 장식이 아니라 다양한 관심사가 모여 쿠러그를 만든다는 의미를 가짐

인터랙션과 애니메이션:

- 첫 진입 시 제목과 CTA가 0.4~0.6초 정도로 부드럽게 등장
- 첫 진입 시 큐브들이 흩어진 상태에서 그리드로 정렬
- 마우스 이동 시 큐브가 아주 약하게 회전하거나 parallax 반응
- CTA hover/focus 시 버튼이 2px 이동하고 블록형 그림자가 생김
- `활동 알아보기` 클릭 시 다음 섹션으로 부드럽게 스크롤
- 모바일에서는 큐브 수를 줄이고 텍스트 가독성을 우선

기존 랜딩의 흐릿한 사진 배경 대신, CI의 블록 조형을 Hero의 주인공으로 사용한다.

### 쿠러그는 이런 사람에게 열려 있어요

구성:

- 4개의 블록 카드
- 각 카드에는 대상 문구와 1문장 설명 배치
- 예시 항목:
  - `처음 시작하는 사람`
  - `전공이 다른 사람`
  - `만들고 싶은 사람`
  - `나누고 싶은 사람`

스타일:

- 흰 배경 카드
- `#EEE` border
- 좌상단에 작은 큐브 아이콘 또는 블록 마커
- 부드러운 카드 UI보다 블록 모듈처럼 보이게 구성

인터랙션과 애니메이션:

- 데스크톱에서는 hover/focus 시 카드 테두리와 배경색을 약하게 강조
- hover 시 카드가 2~4px 정도 위로 이동하거나 작은 블록이 한 칸 이동
- 모바일에서는 tap 시 눌림 상태를 짧게 표현
- 섹션 진입 시 전체가 한 번에 은은하게 fade-in
- 카드가 과하게 순차 등장하거나 튀어 오르는 효과는 사용하지 않음

### 쿠러그에서 하는 활동

구성:

- `그룹`, `교육`, `세미나`, `트랙` 탭
- 선택된 탭에 따라 설명 영역 변경
- 데스크톱: 왼쪽 탭, 오른쪽 설명
- 모바일: 상단 가로 탭, 아래 설명

스타일:

- 둥근 pill 대신 사각 블록 버튼
- active 탭은 `#00A0E9`
- inactive 탭은 `#EEE`
- 설명 영역은 흰 배경과 좌측 파란 블록 라인

인터랙션과 애니메이션:

- 탭 hover/focus 시 배경색을 약하게 변경
- active 탭은 명확하게 구분
- 탭 전환 시 active 블록이 옆으로 미끄러지는 느낌
- 설명 내용은 150~220ms 정도의 opacity와 작은 translate로 전환
- 큰 스크롤 애니메이션은 사용하지 않음

활동 설명은 정보량이 늘어나기 쉬우므로 탭 구조로 압축한다.

### 관심 분야

구성:

- 관심 분야를 사각 칩으로 표시
- 데스크톱: 여러 줄로 자연스럽게 흐르는 태그 그룹
- 모바일: 2열 배치 또는 짧은 가로 스크롤
- 예시:
  - 웹/앱
  - AI/머신러닝
  - 보안/해킹
  - 게임/VR
  - IoT/로봇
  - 알고리즘
  - UX/UI
  - 데이터 사이언스
  - 클라우드/DB
  - 네트워크

스타일:

- 기본 칩은 `#EEE`
- hover/focus 시 `#79C7EA`
- selected 상태는 `#00A0E9` 또는 `#013E8D`
- 둥근 pill보다 각진 버튼 형태

인터랙션과 애니메이션:

- 칩을 선택하면 아래에 짧은 설명 표시
- 선택된 칩 옆에 작은 큐브 조각을 붙여 identity 강화
- 선택 상태는 하나만 유지해도 충분
- 칩 hover scale은 1.02 정도로 제한
- 선택된 설명이 바뀔 때 짧게 fade
- 태그들이 계속 움직이는 marquee 형태는 사용하지 않음

### 최근 활동

구성:

- Hello 블로그 최신 글 3개
- 각 카드에 카테고리, 제목, 날짜, 짧은 설명 또는 썸네일 포함
- 하단 CTA: `Hello 블로그 보기`
- 데스크톱 3열, 모바일 1열

스타일:

- 카드 상단에 `#00A0E9` 사각 바
- 이미지가 없는 경우 블록 패턴 placeholder 사용
- 카드 수와 높이를 제한해 글 목록이 랜딩의 중심이 되지 않도록 함

인터랙션과 애니메이션:

- 카드 전체 클릭 가능
- hover/focus 시 제목 밑줄 또는 카드 테두리 강조
- hover/focus 시 상단 바가 카드 너비만큼 확장
- 썸네일이 있다면 hover 시 3~5% 정도만 확대
- 카드가 계속 움직이거나 자동 슬라이드되는 방식은 피함

### 가입 안내

구성:

- 4단계 stepper:
  - `온라인 신청`
  - `검토`
  - `면접`
  - `회원 등록`
- 대상: `경희대학교 학생`
- 주요 CTA: `가입 신청하기`
- 보조 정보: `we_are@khlug.org`

스타일:

- 원형 번호가 아니라 정육면체 블록 4개가 이어진 형태
- 각 단계는 사각 블록으로 표현
- 마지막 CTA는 `#00A0E9` 배경

인터랙션과 애니메이션:

- 단계 hover/focus 시 짧은 설명 표시
- CTA hover/focus 시 블록형 그림자 또는 2px 이동
- 이메일은 `mailto:` 링크 또는 클릭 시 복사 기능 제공
- stepper는 기본적으로 정적인 상태 유지
- 필요하다면 섹션 진입 시 아주 짧은 fade-in 정도만 사용

가입 안내는 마지막 행동을 만드는 섹션이므로, 장식보다 절차와 CTA를 명확히 보여준다.

## Hero 집중 애니메이션 아이디어

랜딩 전체에서 가장 강한 애니메이션은 Hero에 집중한다.

권장 컨셉:

- 인터랙티브 블록/큐브 배경
- 큐브들이 느리게 연결되고 정렬됨
- 사용자의 마우스 위치에 따라 근처 큐브가 약하게 반응함
- 일부 큐브는 관심 분야 태그로 전환됨
- 페이지 진입 시 큐브들이 한 번 정렬되며 타이틀이 등장

표현하고 싶은 인상:

- 쿠러그는 다양한 관심사가 연결되는 곳
- 기술을 배우고, 만들고, 공유하는 곳
- 정적인 소개 페이지가 아니라 실제 활동이 있는 IT 동아리

주의할 점:

- 배경 애니메이션은 본문보다 낮은 대비로 처리
- 텍스트 위를 지나가는 선이나 입자는 최소화
- 모바일에서는 단순한 블록 배경이나 정적인 그래픽으로 대체 가능
- 성능 부담이 큰 canvas 효과는 기기 성능에 따라 degrade 가능해야 함

## 피해야 할 것

- 모든 섹션에 강한 스크롤 등장 애니메이션을 넣는 것
- 글을 읽는 동안 계속 움직이는 배경이나 카드
- 자동 슬라이드되는 최근 활동 카드
- 관심 분야 태그가 계속 흘러가는 marquee
- hover에서만 중요한 정보가 나타나는 구성
- 랜딩 첫 화면에서 로그인 버튼이 가입 CTA보다 강하게 보이는 구성
- 장비, 연혁, 행사 상세 등 메인 목적에서 벗어나는 정보 과다 노출
- 과한 gradient hero
- 둥근 pill/card 남발
- 흐릿한 사진 위에 텍스트를 올리는 기존 방식 반복
- 블로그 글 목록 중심 구성
- 보라색 또는 남색 위주의 컬러 확장으로 브랜드 컬러가 흐려지는 것
- 장식용 큐브가 본문 가독성을 방해하는 것

전체 페이지는 조용하고 읽기 쉬워야 한다. 화려함은 Hero에서 한 번 강하게 보여주고, 이후 섹션은 사용자가 직접 눌러보고 탐색하는 작은 인터랙션 중심으로 구성한다.

새 랜딩은 CI 심볼의 정육면체 블록이 페이지 전체의 레이아웃 언어가 되는 구조를 목표로 한다. Hero에서 블록이 움직이고 조립되며 강한 첫인상을 만들고, 이후 섹션에서는 같은 블록 규칙을 차분하게 반복해 브랜드 일관성을 유지한다.
